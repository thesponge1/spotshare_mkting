```markdown
## AEO Requirements (Apply to Every Page)

Every page generated by this skill must be optimized not just for traditional search rankings but for citation by AI systems — specifically ChatGPT (with search) and Google AI Overviews. These requirements are non-negotiable and should be treated as part of the page template, not optional extras.

### Required HTML Elements

**1. Key Takeaways / TL;DR box**
Place a bullet-point summary box immediately after the hero section and before the first content section. Use 4–6 bullets. Each bullet should be a self-contained, AI-extractable fact. This is the first thing AI systems will pull for summarization queries.

**2. "What Is [Company]?" definition block**
In the first content section, include a short 2–3 sentence plain-English definition of the company/product. AI systems need a direct, quotable definition to cite when someone asks "what is [your brand]?" Do not assume the reader already knows who you are.

**3. Visible "Last Updated" date**
Display a "Last updated: [Month Year]" line near the top of the page — ideally below the hero headline or byline. AI systems heavily weight content recency. Undated content loses to dated content. This is a one-line change with real citation impact.

**4. Linked source citations**
Every source note must use real `<a href>` links pointing to the source domain. Plain-text citations are not enough — AI systems follow links to verify claims. Unlinked citations do not signal credibility to AI crawlers.

**5. Native `<details>`/`<summary>` FAQ accordion**
If the page includes an FAQ section, the accordion must use HTML5 `<details>` and `<summary>` elements — NOT JavaScript that sets `display: none` on page load. FAQ answers hidden by JavaScript may not be indexed by AI crawlers. With `<details>`, answers are always present in the DOM.

Example pattern:
```html
<details class="faq-item">
  <summary>Question text here</summary>
  <div class="faq-a">
    <p>Answer text here</p>
  </div>
</details>
```

**6. Semantic HTML structure**
- Wrap the main editorial content in `<main>` tags
- Wrap article/editorial sections in `<article>` tags
- Nav and footer should remain outside these wrappers

**7. Speakable `id` attributes**
Add `id="speakable-intro"` to the hero intro paragraph and `id="speakable-model"` (or equivalent) to the key explanatory paragraph in the main content body. These are referenced in the Speakable schema (see below).

---

### Required Schema Markup (JSON-LD)

Every page must include a single `<script type="application/ld+json">` block in the `@graph` format containing ALL of the following schema types:

**Required schemas — include every one:**

| Schema Type | Purpose |
|-------------|---------|
| `WebPage` with `SpeakableSpecification` | Tells AI assistants which paragraphs to quote |
| `BreadcrumbList` | Page hierarchy for AI navigation context |
| `Article` with `datePublished`, `dateModified`, `author`, `publisher` (with `logo`), and `about` array | Establishes content as a dated, authored, on-topic article |
| `Organization` with full `description` and `logo` | Registers the company as a known entity in AI knowledge graphs |
| `HowTo` | Marks step-by-step process content (e.g. implementation timelines) as extractable for AI process queries |
| `FAQPage` with all questions and full answer text | Registers Q&A content for direct AI Overview extraction |

**Template for the full schema block:**

```json
{
  "@context": "https://schema.org",
  "@graph": [
    {
      "@type": "WebPage",
      "@id": "https://[site]/[page-url]",
      "url": "https://[site]/[page-url]",
      "name": "[Page Title]",
      "speakable": {
        "@type": "SpeakableSpecification",
        "cssSelector": ["#speakable-intro", "#speakable-model"]
      }
    },
    {
      "@type": "BreadcrumbList",
      "itemListElement": [
        {"@type": "ListItem", "position": 1, "name": "Home", "item": "https://[site]"},
        {"@type": "ListItem", "position": 2, "name": "[Section]", "item": "https://[site]/[section]"},
        {"@type": "ListItem", "position": 3, "name": "[Page Name]", "item": "https://[site]/[page-url]"}
      ]
    },
    {
      "@type": "Article",
      "headline": "[Page Headline]",
      "description": "[1-2 sentence summary of the page]",
      "datePublished": "[YYYY-MM-DD]",
      "dateModified": "[YYYY-MM-DD]",
      "author": {
        "@type": "Organization",
        "name": "[Company Name]",
        "url": "https://[site]"
      },
      "publisher": {
        "@type": "Organization",
        "name": "[Company Name]",
        "url": "https://[site]",
        "logo": {
          "@type": "ImageObject",
          "url": "https://[site]/assets/images/[company]-logo.png"
        }
      },
      "mainEntityOfPage": {
        "@type": "WebPage",
        "@id": "https://[site]/[page-url]"
      },
      "about": [
        {"@type": "Thing", "name": "[Primary topic]"},
        {"@type": "Thing", "name": "[Secondary topic]"},
        {"@type": "Place", "name": "[City/Location if applicable]"}
      ]
    },
    {
      "@type": "Organization",
      "name": "[Company Name]",
      "url": "https://[site]",
      "description": "[2-3 sentence plain-English description of what the company does, who it serves, and what problem it solves]",
      "logo": {
        "@type": "ImageObject",
        "url": "https://[site]/assets/images/[company]-logo.png"
      }
    },
    {
      "@type": "HowTo",
      "name": "[Title of the process — e.g. 'How an HOA Board Activates a Shared Guest Parking System']",
      "description": "[1-2 sentence description of what this process covers]",
      "totalTime": "[ISO 8601 duration — e.g. PT6W for 6 weeks]",
      "step": [
        {
          "@type": "HowToStep",
          "position": 1,
          "name": "[Step name]",
          "text": "[Step description including typical timeline if relevant]"
        }
      ]
    },
    {
      "@type": "FAQPage",
      "mainEntity": [
        {
          "@type": "Question",
          "name": "[Question text — match how people actually ask it]",
          "acceptedAnswer": {
            "@type": "Answer",
            "text": "[Full answer text — self-contained, no references to 'above' or 'below']"
          }
        }
      ]
    }
  ]
}
```

**Rules for FAQ schema answers:**
- Each answer must be self-contained — AI will extract it with no surrounding context
- Do not reference "as mentioned above" or "see section X"
- Keep answers factual and specific — generic answers don't get cited
- Include all FAQ questions from the page, not just a subset

<meta name="twitter:title" content="[Page title]" />
<meta name="twitter:description" content="[Meta description]" />
<meta name="twitter:image" content="https://[site]/assets/images/[city]-og.png" />
```

## Why These Requirements Exist

These changes came out of a direct comparison between a base programmatic SEO city page and an AEO-optimized version of the same page for SpotShare's San Diego city page. The original page already had BreadcrumbList, Article, Organization, and FAQPage schemas — but was still missing:

- Speakable schema (tells AI which paragraphs to quote)
- HowTo schema (makes step-by-step content eligible for AI process answer cards)
- TL;DR box (gives AI a ready-made answer block near the top)
- "What Is [Company]?" definition (makes the brand citable as a known entity)
- Linked source citations (AI can't verify unlinked claims)
- Native `<details>` FAQ (JS-hidden answers may not reach AI crawlers)
- Visible "Last Updated" date near page top (recency signal)

These are not nice-to-haves — the Princeton GEO research (KDD 2024) found cited sources increased by +40% when authoritative citations were added, and AI systems demonstrably weight structured, dated, authored content over unstructured content.
